# Bomb Raiders

Bomb Raiders is a 2D single-player bombing game developed in C++ as a personal game-development and programming learning project.

## Technology

- C++
- SFML 3
- CMake
- Visual Studio Code
- MSYS2 UCRT64 / GCC
